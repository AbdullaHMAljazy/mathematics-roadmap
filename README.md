# Mathematics Roadmap: Books and Video Courses

A roadmap for learning mathematics, from first principles to current research, that pairs **books** with **video courses** for every topic.

- **Books and topic structure:** [Talal Al-Rawajfeh's Mathematics Roadmap](https://github.com/TalalAlrawajfeh/mathematics-roadmap).
- **Video courses:** collected by [Abdullah M. Al-jazy](https://abdullahmaljazy.github.io/). Courses marked 🆕 were found by a web search in November 2026.
- **Browse it as a web page:** [abdullahmaljazy.github.io/roadmap.html](https://abdullahmaljazy.github.io/roadmap.html)

**54 topics · 198 books · 203 video courses and lecture series** (all links checked on 19 November 2026).

## How to use this roadmap

Topics are grouped into areas and listed roughly in the order you would learn them. For the exact prerequisites between topics, see the [dependency diagram](https://github.com/TalalAlrawajfeh/mathematics-roadmap/blob/master/mathematics-roadmap.jpg) in Talal's roadmap: an arrow from A to B means B builds on A.

For each topic you do not need every book or course. Read the preface and table of contents of a few books, watch the first lecture of a few courses, and pick the ones that suit you. Topics marked _optional_ can be skipped; _optional but recommended_ ones are very useful. Topics marked _new topic_ are not in Talal's original roadmap.
